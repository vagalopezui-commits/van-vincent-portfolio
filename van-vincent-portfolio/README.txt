# Van Vincent Lopez — Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, scroll animations, and dynamic year

## How to run
1. Put all three files in the same folder.
2. Open `index.html` in your browser.
3. Replace the placeholder email and GitHub link in `index.html`.
4. Add your real project links/screenshots when available.

## Publishing
You can publish this free with GitHub Pages, Netlify, or Vercel.
